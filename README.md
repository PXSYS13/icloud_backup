## Зачем это нужно

В России трудно оплатить iCloud+. Подписка заканчивается, хранилище переполняется, и айфон перестаёт делать резервные копии и выгружать новые фото. Сайт iCloud.com позволяет скачать не больше 1000 файлов за раз, а в семейной медиатеке их обычно десятки тысяч.

Программа решает это одной кнопкой: вы входите в свой Apple ID, выбираете папку, и она скачивает всю медиатеку iCloud Фото на компьютер. Дальше фото можно хранить на внешнем диске, перенести в Яндекс Диск или просто освободить место в iCloud, зная, что всё сохранено.

## Что умеет

- **Скачивает всё и в оригинале.** Фотографии, видео и Live Photos — так, как они лежат в iCloud, без сжатия. Live Photos сохраняются двумя файлами рядом: сама фотография и её видеочасть (`.MOV`) с тем же именем.
- **Продолжает с того же места.** Закрыли окно, пропал интернет, перезагрузился компьютер — при следующем запуске скачанное второй раз не качается.
- **Показывает, что происходит.** Сколько уже скачано, скорость, сколько осталось по времени. Есть пауза и продолжение.
- **Сама переживает ошибки.** Если Apple не отвечает, программа ждёт и повторяет попытку, с каждой неудачей пауза становится длиннее.
- **Сохраняет дату съёмки.** Дата съёмки хранится в базе программы и ставится файлу как дата изменения, поэтому в проводнике фото можно сортировать по дате.
- **Раскладывает по годам и месяцам.** Например, `2023/2023-07/IMG_0001.HEIC`. Включено по умолчанию, можно выключить — тогда все файлы лягут в одну папку.
- **Делает JPG-копии, если нужно.** По умолчанию формат «Оригиналы»: файлы HEIC остаются как есть. Можно выбрать «JPG-копии» (рядом появится JPG, а оригинал HEIC переедет в подпапку `_heic_originals`) или «Оба» (JPG рядом с HEIC). JPG сохраняет данные снимка: дату и место съёмки. Ничего не удаляется.
- **Находит одинаковые файлы.** Дубликаты определяются по содержимому и переносятся в папку `_duplicates`, а не удаляются.
- **Умеет заливать копию в Яндекс Диск.** По желанию: та же структура папок в папке «iCloud БК» на Диске, файлы, которые там уже есть, пропускаются, свободное место проверяется заранее.
- **Всё хранится только у вас.** Пароль от Apple ID программа не сохраняет, никуда ничего не отправляет и в iCloud ничего не удаляет и не меняет — только читает.

## Что включить на айфоне

Это обязательный шаг. Без него Apple отвечает ошибкой ACCESS_DENIED и не даёт программе доступ к фото.

1. **Выключите «Расширенную защиту данных»**, если она включена: «Настройки» → ваше имя → iCloud → «Расширенная защита данных» → отключить. После скачивания её можно включить обратно.
2. **Включите доступ к данным iCloud через интернет:**
   - iOS до 26.3 включительно: «Настройки» → ваше имя → iCloud → включите «Доступ к данным iCloud в интернете»;
   - iOS 26.4 и новее: «Настройки» → ваше имя → iCloud → iCloud.com → включите «Разрешить доступ к данным».

Порядок важен: пока включена «Расширенная защита данных», Apple сама выключает доступ через интернет. После изменения настроек подождите несколько минут.

Ещё два условия: у Apple ID должна быть включена двухфакторная проверка (у всех современных Apple ID она уже есть), и вход должен быть по коду, а не по аппаратному ключу безопасности (FIDO) — такие ключи движок программы не поддерживает.

## Как начать

Настройка займёт 10 минут, дальше программа качает сама. Ставить Python или что-то ещё вручную не нужно.

1. **Подготовьте айфон** — два переключателя из раздела выше.
2. **Скачайте** [программу (ZIP-архив)](https://github.com/PXSYS13/icloud_backup/archive/refs/heads/main.zip) и распакуйте: правой кнопкой по архиву → «Извлечь всё».
3. **Запустите:**
   - Windows — двойной клик по `webui.bat`. Если Windows покажет «Windows защитил ваш компьютер» — «Подробнее» → «Выполнить в любом случае»;
   - macOS — двойной клик по `webui.command`;
   - Linux — `bash webui.sh` в папке программы.

   В первый раз программа 1–2 минуты скачивает всё нужное, потом сама открывает страницу в браузере. Если не открыла — наберите в браузере адрес из строки «Адрес» в чёрном окне программы, обычно `localhost:8000`.
4. **Войдите в Apple ID.** Введите Apple ID и пароль, затем код подтверждения, который придёт на айфон, — в том же окне.
5. **Выберите папку и нажмите «Проверить медиатеку», затем «Скачать всё».** Программа сначала покажет, сколько в медиатеке фото и видео и сколько места они займут, и предупредит, если места на диске не хватит. Можно и сразу «Сразу скачать всё» — список она соберёт сама.
6. **Не закрывайте чёрное окно программы** — пока оно открыто, программа работает. Браузер закрывать можно.

Что нужно: Windows 10 или 11 (основная система), macOS или Linux; интернет; свободное место на диске примерно по размеру медиатеки.

Каждый шаг с подсказками и что делать, если что-то пошло не так, — в [пошаговой инструкции](https://github.com/PXSYS13/icloud_backup/blob/main/INSTRUCTION.md).

## Копия в Яндекс Диск

Если хотите, программа зальёт скачанное в Яндекс Диск — в папку «iCloud БК», с теми же папками по годам и месяцам. Файлы, которые на Диске уже есть, она узнаёт по содержимому и пропускает, а перед загрузкой проверяет, хватит ли места. Если Яндекс просит обращаться реже (ошибка 429), программа делает паузу и продолжает сама.

Заливается основная папка с фото; служебные подпапки `_duplicates` и `_heic_originals` на Диск не копируются.

Для этого нужен ключ доступа к Диску — тот же, что в «Яндекс БК». Как его получить за пять минут, рассказано в [пошаговой инструкции](https://github.com/PXSYS13/yadisk_backup/blob/main/INSTRUCTION_GET_TOKEN.md).

> [!IMPORTANT]
> Загрузка через программу занимает обычное место на Диске, как любые файлы. Безлимит для фото Яндекс даёт только автозагрузке из своего мобильного приложения. Если на Диске мало места, залейте только самое важное или увеличьте тариф.

## Частые вопросы

<details>
<summary><b>Это бесплатно? Это безопасно?</b></summary>

Программа бесплатная, с открытым кодом (лицензия MIT). Её можно проверить: весь код — в этом репозитории. Для входа в iCloud она использует открытый движок [icloudpd](https://github.com/icloud-photos-downloader/icloud_photos_downloader), которым люди по всему миру пользуются много лет.

- Всё работает на вашем компьютере. Страница `localhost:8000` — это пульт управления, из интернета она недоступна.
- Пароль от Apple ID программа не сохраняет. Хранится только сессия — данные входа, которые выдала Apple, — в папке `session/` внутри папки программы. Кнопка «Выйти» её удаляет.
- Пароли, коды подтверждения и ключи доступа не попадают в журналы и отчёт для поддержки.
- Программа только читает из iCloud. Она не удаляет и не меняет там ничего, что бы ни случилось.
- Никакой статистики, никаких сторонних серверов: программа обращается только к Apple и, если вы включили загрузку, к Яндексу. При первом запуске `webui.bat` один раз скачивает с официального сайта установщик uv — он ставит Python и зависимости программы.

Программа неофициальная и не связана с Apple.
</details>

<details>
<summary><b>Код подтверждения не приходит</b></summary>

Подождите минуту: иногда код задерживается. Если не пришёл, попросите новый прямо на айфоне: «Настройки» → ваше имя → «Пароль и безопасность» → «Получить код подтверждения». Код может прийти и на другое устройство Apple, где выполнен вход в этот же Apple ID, — проверьте айпад или мак.
</details>

<details>
<summary><b>Ошибка ACCESS_DENIED</b></summary>

Apple не даёт доступ к фото через интернет. На айфоне выключите «Расширенную защиту данных» и включите доступ к данным iCloud через интернет — точные пути в разделе [«Что включить на айфоне»](#что-включить-на-айфоне). Подождите несколько минут, нажмите «Выйти» и войдите заново.
</details>

<details>
<summary><b>Почему нужно выключать «Расширенную защиту данных»?</b></summary>

При включённой «Расширенной защите данных» Apple не даёт доступ к фото через интернет — ни сайту iCloud.com, ни программам. А программа получает фото именно так, как их отдаёт iCloud.com. Поэтому на время скачивания защиту нужно выключить. Когда всё скачается, её можно включить обратно.
</details>

<details>
<summary><b>Программа пишет, что сессия истекла</b></summary>

Apple выдаёт вход примерно на два месяца, а иногда завершает его раньше — например, после смены пароля. Просто войдите заново: Apple ID, пароль и код подтверждения. Скачивание продолжится с того же места, уже скачанное не качается снова.
</details>

<details>
<summary><b>Подписка iCloud+ закончилась, хранилище переполнено. Я ещё могу скачать фото?</b></summary>

Да. На [странице поддержки Apple для России](https://support.apple.com/ru-ru/126891) сказано, что после окончания подписки данные остаются доступными: вы по-прежнему можете управлять хранилищем и скачивать фотографии и видео из iCloud. Новые фото с айфона при переполненном хранилище перестают выгружаться, но то, что уже в iCloud, скачать можно. Лучше не откладывать.
</details>

<details>
<summary><b>Файлы HEIC не открываются на Windows</b></summary>

HEIC — формат, в котором айфон снимает фото. Windows без дополнений его не показывает. Два пути:

- в программе на экране «Обработка» выберите «JPG-копии» или «Оба» — рядом с каждым HEIC появится JPG, который открывается везде;
- или установите «Расширения для изображений HEIF» из Microsoft Store — тогда HEIC откроется и в обычном просмотре фото.
</details>

<details>
<summary><b>Почему у некоторых фото два файла?</b></summary>

Это Live Photos: короткое видео, снятое вместе с фотографией. Программа сохраняет оба файла рядом с одним именем: `IMG_0001.HEIC` (или `.JPG`) и `IMG_0001.MOV`. Если загрузить их на айфон, он снова соберёт из них живое фото.
</details>

<details>
<summary><b>Не хватает места на диске</b></summary>

Перед началом программа считает размер медиатеки и предупреждает, если места не хватит. Выберите папку на другом диске — например, на внешнем. Если место кончилось во время скачивания, программа остановится и покажет кнопку «Я освободил место — продолжить»: освободите место или выберите другую папку, и скачивание пойдёт дальше с того же места.
</details>

<details>
<summary><b>Почему загрузка в Яндекс Диск занимает место на Диске?</b></summary>

Безлимит для фото Яндекс даёт только автозагрузке из своего мобильного приложения. Всё, что загружено через программу (через интерфейс для программ, API), считается обычными файлами и занимает обычное место. Так устроено у Яндекса, обойти это нельзя.
</details>

<details>
<summary><b>Почему нет правок, которые я делал на айфоне?</b></summary>

Программа скачивает оригиналы — так, как фото было снято. Обрезка, фильтры и другие правки хранятся в iCloud отдельно, и в этой версии они не скачиваются.
</details>

<details>
<summary><b>Можно закрыть браузер или выключить компьютер?</b></summary>

Браузер — можно: программа работает в чёрном окне, а страница в браузере только показывает, что происходит. Чёрное окно закрывать нельзя — вместе с ним остановится скачивание. Если компьютер выключился или перезагрузился, просто запустите программу снова: она продолжит с того же места.
</details>

<details>
<summary><b>Где мои файлы?</b></summary>

В папке, которую вы выбрали перед скачиванием; путь показан на главном экране и на экране «Готово». Внутри файлы лежат по годам и месяцам: `2023/2023-07/IMG_0001.HEIC`. Если вы выключили раскладку, все файлы лежат в одной папке. Оригиналы HEIC после создания JPG-копий — в подпапке `_heic_originals`, одинаковые файлы — в `_duplicates`.
</details>

<details>
<summary><b>Как обновить программу?</b></summary>

Скачайте [архив](https://github.com/PXSYS13/icloud_backup/archive/refs/heads/main.zip) заново, закройте чёрное окно программы и распакуйте архив поверх старой папки, согласившись заменить файлы. Потом запустите программу как обычно. Вход в Apple ID, папка и прогресс скачивания сохранятся: их нет в архиве.
</details>

<details>
<summary><b>Что-то не работает — как попросить помощи?</b></summary>

## Чего нет в этой версии

- Альбомов и общей медиатеки: скачивается вся медиатека целиком, без разделения по альбомам.
- iCloud Drive и других данных, кроме фото и видео.
- Скачивания по расписанию.
- Отредактированных версий фото — только оригиналы.
- Фото из альбома «Скрытые» и из «Недавно удалённых»: скачивается основная медиатека.
- Чего-либо, что меняет iCloud: программа только читает.

## Для продвинутых

<details>
<summary><b>Запуск из командной строки, демо-режим, тесты</b></summary>

Если uv уже установлен:

```bash
git clone https://github.com/PXSYS13/icloud_backup.git
cd icloud_backup
uv run webui.py            # интерфейс на http://127.0.0.1:8000
uv run webui.py --demo     # демо-режим без настоящего Apple ID
uv run pytest -q           # тесты
```

В демо-режиме подойдут любой Apple ID и любой пароль, код подтверждения — `123456`. Вместо iCloud программа работает с небольшой встроенной медиатекой: удобно посмотреть интерфейс, ничего не скачивая.

Настройки можно задать в файле `.env` в папке программы (образец — `.env.example`):

```bash
DOWNLOAD_DIR=D:/iCloudBackup   # папка для фото и видео
YA_DISK_TOKEN=                 # ключ доступа к Яндекс Диску, если нужна загрузка
ICLOUD_BK_PORT=8000            # порт интерфейса
PHOTO_FORMAT=originals         # originals | jpg | both — то же, что «Формат фото» в «Обработке»
LAYOUT_BY_MONTH=1              # 1 — папки по годам и месяцам, 0 — всё в одну папку
```

Если вы ставите зависимости через pip, а не uv (Python 3.10–3.13):

```bash
pip install -r requirements.txt
python webui.py
```
</details>

Как устроен проект, как запускать тесты и присылать изменения — в [руководстве для разработчиков](CONTRIBUTING.md).
