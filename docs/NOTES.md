# Заметки по ходу работы

Одна запись — одна строка с причиной. Новые записи добавляются в конец.

- icloudpd 1.32.3 на PyPI для Windows, macOS и Linux ставится как бинарник PyInstaller (в пакете только `__main__.py`, который запускает `icloudpd.exe`), импортировать его нельзя; чистый Python лежит в отдельном wheel `icloudpd-1.32.3-py3-none-any.whl`, и pip или uv сами его не выберут, потому что платформенный wheel «точнее». Поэтому зависимость зафиксирована прямой ссылкой на этот wheel с хешем sha256.
- Pillow 13 не принимает GPS-координаты в EXIF как кортежи пар `((55, 1), (45, 1), …)` (формат piexif) и падает в `tobytes()`; нужно передавать числа `(55.0, 45.0, 20.88)`, Pillow сам сделает рациональные дроби.
- pillow-heif 1.8 при декодировании HEIC сам применяет поворот из контейнера и сбрасывает EXIF Orientation в 1; поэтому `heic_convert.py` передаёт EXIF как есть, иначе JPG повернулся бы дважды.
- `App.html` из «Яндекс БК» сравнивал новую разметку с `el.innerHTML`, а браузер пересериализует `<path/>` как `<path></path>`, поэтому сравнение всегда проваливалось и кнопки пересоздавались каждые 1,5 секунды (терялся фокус, «протухали» ссылки на элементы). Теперь сравниваем с последней разметкой, которую ставили сами (WeakMap).
- На Windows в PATH бывает `bash.exe` от WSL без установленного дистрибутива: он отвечает ошибкой на любую команду; тест синтаксиса `webui.sh` сначала проверяет, что bash вообще запускается, иначе пропускается.
- Демо-режим держит свои базу (`state_demo.db`), сессию (`session_demo/`) и папку (`downloads_demo/`, ключ `DEMO_DOWNLOAD_DIR` в .env): иначе демо-файлы попали бы в настоящую папку с фото пользователя.
- Пустой пароль-провайдер в `PyiCloudService` не бросает исключение, а молча оставляет `data` пустым; восстановление сессии проверяет `icloud.data`, иначе `requires_2fa` упал бы с KeyError.
